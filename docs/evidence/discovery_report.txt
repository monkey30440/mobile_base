3. As-Built v0.1.0 Mental Model
-------------------------------

Packages and observed responsibilities:

- mobile_base_bringup
  Thin real-hardware Mapping/Navigation mode orchestration.
- mobile_base_control
  M1 Modbus transport, ros2_control SystemInterface, controller launch/config.
- mobile_base_description
  Xacro/URDF, meshes, fixed sensor/wheel geometry, robot_state_publisher.
- mobile_base_perception
  Dual SICK LiDAR, scan merger, and TDK IMU launch/config composition.
- mobile_base_state_estimation
  robot_localization EKF composition.
- mobile_base_mapping
  slam_toolbox lifecycle launch and MapIO read-back test support.
- mobile_base_localization
  map_server, AMCL, and localization lifecycle manager.
- mobile_base_navigation
  Nav2 servers/config, route-assisted BT, and a non-node TargetAdmission library.
- rf2o_laser_odometry
  /scan to /rf2o/odom, with TF publication disabled.
- tdk_ros2_imu
  Serial TDK IMU driver publishing raw IMU data.

Runtime entrypoints:

- Mapping:
  ros2 launch mobile_base_bringup mapping.launch.py
- Navigation:
  ros2 launch mobile_base_bringup navigation.launch.py map:=... route_graph:=...

Mapping mode data flow:

  SICK front -> /scan_front --+
                               +-> dual_laser_merger -> /scan -> RF2O
  SICK rear  -> /scan_rear  --+                          |
                                                          -> /rf2o/odom --+
  TDK IMU ---------------------------> /imu/data_raw --------------------+
  M1 encoders -> diff_drive_controller -> /diff_drive_controller/odom --+
                                                                          |
                                                                          v
                                                        robot_localization EKF
                                                        /odometry/filtered
                                                        odom -> base_footprint
                                                                          |
                              /scan + odom TF -----------------------------+
                                          |
                                          v
                                slam_toolbox -> /map
                                slam_toolbox owns map -> odom

Navigation mode data/control flow:

  map.yaml -> map_server -> /map --------------------+
  /scan + odom -> base_footprint -> AMCL ------------+-> map -> odom

  route_graph.geojson -> route_server
  goal PoseStamped -> bt_navigator
                   -> ComputeRoute
                   -> First Mile connector
                   -> route path
                   -> Last Mile connector
                   -> FollowPath / MPPI
                   -> /cmd_vel_nav
                   -> collision_monitor
                   -> /diff_drive_controller/cmd_vel
                   -> diff_drive_controller
                   -> M1Hardware -> M1Driver -> motors

TF ownership visible in current config:

- robot_state_publisher: fixed geometry and joint-driven robot TF
- diff_drive_controller: odometry topic, enable_odom_tf=false
- RF2O: odometry topic, publish_tf=false
- EKF: sole odom -> base_footprint publisher
- slam_toolbox: mapping-mode map -> odom publisher
- AMCL: navigation-mode map -> odom publisher

Runtime-resource roles:

- maps/test_site/map.yaml + map.pgm:
  Runtime-loadable test-site OccupancyGrid.
- maps/test_site/route_graph.geojson:
  Runtime Route Server graph, currently two nodes and one directed edge.
- maps/template/*:
  Four tracked zero-byte placeholders, not directly usable sample data.
- Production station catalog:
  Not present.
- Station parser:
  Present in TargetAdmission library and unit-test fixtures.
- Runtime Station/Goal admission node or CLI:
  Not present in this repository.
