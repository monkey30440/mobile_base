# UC-001 建圖任務（Mapping）

## 1. 目的

建立可供定位與導航使用之二維地圖。

對應 Capability：**CAP-001 建立可重複使用之地圖**

---

## 2. 使用者

- 開發人員
- 測試人員

---

## 3. 說明

使用者透過終端啟動建圖模式，並以鍵盤控制 AMR 移動。

系統於移動過程中執行 SLAM，完成環境地圖建立並儲存地圖檔。

---

## 4. 前置條件

- AMR 已完成開機。
- ROS 2 系統已啟動。
- LiDAR、IMU、底盤驅動正常運作。
- 建圖相關節點已啟動。

---

## 5. 操作流程

| 步驟 | 操作 |
|------|------|
| 1 | 啟動建圖模式。 |
| 2 | 啟動鍵盤遙控。 |
| 3 | 控制 AMR 完成環境巡航。 |
| 4 | 儲存地圖。 |
| 5 | 完成建圖任務。 |

---

## 6. 輸入

| 項目 | 說明 |
|------|------|
| Keyboard Command | 鍵盤控制指令 |

---

## 7. 輸出

| 項目 | 說明 |
|------|------|
| Map | Occupancy Grid 地圖 |
| map.yaml | 地圖設定檔 |
| map.pgm | 地圖影像檔 |

---

## 8. 完成條件

- 完成環境地圖建立。
- 成功產生 `map.yaml`。
- 成功產生 `map.pgm`。

---

## 9. 驗證方式

於實機完成建圖流程，確認地圖可供後續定位與導航使用。
