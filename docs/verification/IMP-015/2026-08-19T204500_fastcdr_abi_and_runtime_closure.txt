1. ROOT CAUSE OF ABI INCOMPATIBILITY
--------------------------------------------------------------------------------
The base Docker image (nvcr.io/nvidia/isaac/ros:isaac_ros_740c8500df2685ab1f4a4e53852601df-arm64-jetpack)
contained an older build of Fast-CDR (2.2.5) and Fast-RTPS. When running apt-get to install
ros-jazzy-ros2-control and ros-jazzy-ros2-controllers, newer dependencies (such as
ros-jazzy-pal-statistics) were installed that were compiled against Fast-CDR 2.2.7 where primitive
serialization functions were explicitly mangled and exported.
This resulted in a runtime symbol lookup error:
  symbol lookup error: /opt/ros/jazzy/lib/libpal_statistics.so: undefined symbol: _ZN8eprosima7fastcdr3Cdr9serializeEj
causing ros2_control_node to crash immediately upon launch.
