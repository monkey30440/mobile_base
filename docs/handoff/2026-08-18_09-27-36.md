## RF2O Jazzy Compatibility Fix

`rf2o_laser_odometry/package.xml` contained two stale dependencies:

``` xml
<build_depend>cmake_modules</build_depend>
<run_depend>cmake_modules</run_depend>
```

A repository-wide grep showed `cmake_modules` occurred **only** in those
two `package.xml` lines; it was not used by `CMakeLists.txt` or source
code.

Those two lines were removed.

Do **not** remove:

``` xml
<buildtool_depend>eigen3_cmake_module</buildtool_depend>
```

After the two stale lines were removed:

``` bash
rosdep install --from-paths src --ignore-src -r -y
```

completed successfully.

This is intentionally a minimal metadata compatibility fix; no RF2O
runtime behavior was changed.
